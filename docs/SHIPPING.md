## You must do — Android release signing (one time)
The keystore password is your secret, so you run this (not committed):

```powershell
# 1. Create an upload keystore (answer the prompts; remember the passwords)
keytool -genkey -v -keystore $env:USERPROFILE\shattab-upload.jks `
  -keyalg RSA -keysize 2048 -validity 10000 -alias upload

# 2. Create android/key.properties (gitignored) with:
#    storePassword=<the store password>
#    keyPassword=<the key password>
#    keyAlias=upload
#    storeFile=C:\\Users\\<you>\\shattab-upload.jks

# 3. Rebuild — now properly signed
flutter build appbundle --release
```
Back up `shattab-upload.jks` somewhere safe — lose it and you cannot update the app on Play.

## You must do — accounts / dashboard (no login works without #1)
1. **Supabase → Auth → Phone provider: enable it**, and connect an SMS gateway
   (Twilio / MessageBird / Vonage) with credit that delivers to Egypt `+20`.
   Until this is done, nobody can sign in. Set OTP rate limits to cap SMS cost.
2. **Google Play Console** account ($25 one-time) → create app → Internal testing
   → upload the `.aab` → add testers → share the opt-in link (downloadable).
3. **Privacy policy URL** (mandatory — app collects phone, photos, location text).
   Fill Play "Data safety" form.
4. iOS only: **Apple Developer** ($99/yr) + a Mac to build/sign + App Store privacy labels.
