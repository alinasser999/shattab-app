# Admin Test Matrix

## Automated checks run in this repository

| Check | Result |
| --- | --- |
| `npm run audit:contracts` | Passed |
| `npm run typecheck` | Passed |
| `npx next build` | Passed |

The production build is the important route check because it catches illegal
exports and App Router boundary errors that `tsc --noEmit` does not.

## Required staging tests before deployment

1. Run the new migration against a staging project.
2. Test a normal user calling each admin RPC directly and assert `not_authorized`.
3. Test a moderator calling billing and manual-plan RPCs and assert `not_allowed`.
4. Approve, reject, and double-submit one verification and payment request.
5. Resolve post, comment, profile, brief, and review reports with the supported
   action set and verify the Flutter-side result.
6. Verify private document URLs expire and cannot be generated by a normal user.
